# bharatsingh7.github.io

Sci-fi portfolio of **Bharat Singh Bhati**: Software Developer, Machine Vision & IoT, On-Device AI.

Live: https://bharatsingh7.github.io/

Plain HTML/CSS/JS with no build step and no frameworks. All art is generated in code (SVG and canvas).

- `js/robot.js`: ARIA, the robot assistant, and its local chat answers
- `js/drone.js`: the drone that follows the cursor
- `js/background.js`: starfield, nebula and grid floor
- `js/slider.js`: project carousel and the generated art on each slide
- `js/main.js`: boot screen, typing effect, reveals, skill hexes, tilt cards

Run locally: `python3 -m http.server 8080`, then open http://localhost:8080
To update the resume, replace `assets/Bharat_Singh_Bhati_Resume.pdf`.
