# bharatsingh7.github.io

Portfolio of **Bharat Singh Bhati**: software developer working on machine vision, IoT and on-device AI.

Live: https://bharatsingh7.github.io/

Static HTML, CSS and JS with no build step. three.js loads from jsDelivr through an import map.

- `js/scene.js`: the 3D hero (desk, monitor terminal, ARIA robot) and the 3D drone that follows the cursor
- `js/main.js`: ARIA's chat answers, nav, scroll reveals and the project art canvases
- `css/style.css`: all styles; colour tokens are at the top

Run locally: `python3 -m http.server 8080`, then open http://localhost:8080
To update the resume, replace `assets/Bharat_Singh_Bhati_Resume.pdf`.
